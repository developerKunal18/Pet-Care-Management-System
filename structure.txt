# Pet Care Management System
This project helps pet owners manage pet information, vaccination dates, feeding schedules, grooming appointments, and medical visit records.
Features
- Register multiple pets.
- Store pet name, type, breed, age, and owner details.
- Record feeding schedules.
- Track vaccination dates.
- Manage grooming appointments.
- Maintain medical visit history.
- Search pets by name or ID.
- View upcoming care activities.
- Generate pet care reports.
- Store records in JSON files.
